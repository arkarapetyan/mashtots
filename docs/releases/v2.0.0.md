## Highlights

- **New best score: 0.97598 private / 0.97554 public** on the Kaggle leaderboard with an ensemble of ResNet-18 and a new Vision Transformer, up from 0.968 public in v1.0.0.
- New **Vision Transformer** (convolutional patch stem, AdamW, warmup + cosine schedule, weight averaging).
- **Confusion-aware loss** that targets look-alike letters and upper/lowercase pairs, with new case-confusion metrics.
- **Ensemble prediction** with optional shift test-time augmentation.
- Faster data loading, mixed precision by default, and per-model training recipes.

## Changes

**Models and training**

- Vision Transformer (`model=vit`): 8 blocks, width 192, 6 heads, 4 × 4 patches from a convolutional stem, stochastic depth, AdamW with warmup + cosine decay, gradient clipping, 200-epoch schedule.
- Weight averaging (EMA) for any model (`callback.weight_averaging.enabled`), on by default for the ViT.
- Confusion-aware loss: label-smoothed cross-entropy plus a pairwise term against each letter's other-case twin and its most frequent mistakes, with adaptive class weights from the training confusion matrix.
- New metrics: plain accuracy (`*_acc`, the Kaggle metric), case-insensitive accuracy (`*_letter_acc`) and wrong-case rate (`*_case_swap`); MLflow now also gets a list of the most-confused letter pairs.
- Per-model recipes in `configs/model/`, including `efficientnet_lowmem` (gradient accumulation) for GPUs with less memory.
- Mixed precision chosen automatically (`trainer.precision: auto`) and TF32 on newer GPUs.

**Data**

- Elastic augmentation fixed: the previous settings only added pixel noise; strokes are now warped smoothly, and a faster implementation makes data loading about 3× faster.
- Narrower scale augmentation to keep the size cue between upper- and lowercase letters; shear up to 10° for writer slant.
- Dataset download repaired: it no longer skips an empty `data/` folder and reports Kaggle authentication problems clearly.

**Inference and export**

- Ensembles of `.pt2` and `.onnx` models with optional weights and shift test-time augmentation.
- Exports are made on CPU, so `.pt2` files load on any machine.

**Fixes**

- Early stopping monitored `val_acc` with `mode="min"` and stopped runs after `patience` epochs regardless of progress.
- `trainer.test()` crashed; `data.test_ratio` now holds out a labeled test split.
- Training is seeded, checkpoints store their hyperparameters, and `num_workers=0` works.

## Breaking changes

- Models are selected with `model=<name>` (Hydra config groups) instead of `model.model_name=...`; `configs/vit_config.yaml` is removed.
- `predict.py` takes a list: `'model.model_paths=[...]'` instead of `model.model_path=...`.
- `val_acc` is now plain accuracy instead of macro-averaged accuracy, so values differ slightly from v1.0.0 runs.
- PyTorch is installed from PyPI instead of the PyTorch CUDA 12.8 index (the same CUDA 12.8 build on Linux).
